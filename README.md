# FitTrack

**FitTrack** — персональный PWA-трекер силовых тренировок, рабочих весов и изменений массы тела. Приложение рассчитано на использование со смартфона и компьютера: его можно открыть в браузере или установить на главный экран как приложение.

- **Открыть приложение:** https://kirushakaichenkov1111-hub.github.io/fittrack-pwa/
- **Репозиторий:** https://github.com/kirushakaichenkov1111-hub/fittrack-pwa
- **Язык интерфейса:** русский
- **Тип приложения:** Progressive Web App (PWA)
- **Хранение данных:** локально в браузере на устройстве пользователя

## Возможности

### Тренировки
- Три готовые тренировки по циклу A / B / C.
- Отображение упражнений, рекомендуемого диапазона повторений и времени отдыха.
- Ввод рабочего веса и количества повторений отдельно для каждого подхода.
- Отметка выполненных подходов и индикатор общего выполнения тренировки.
- Возможность добавить дополнительный подход к упражнению.
- Автоматическое сохранение незавершённой тренировки в локальный черновик.
- Отображение результата предыдущего выполнения упражнения, если он есть.
- Карточка техники упражнения с описанием, задействованными мышцами и иллюстрацией/анимацией, если она доступна.
- Отображение личного рекорда по упражнению.

### Таймер отдыха
- Запуск таймера из карточки упражнения.
- Готовые интервалы: 45, 60, 75, 90 и 120 секунд.
- Пользовательский интервал от 15 до 600 секунд с шагом 5 секунд.
- Пауза, продолжение и сброс таймера.
- Настраиваемые звуковой сигнал и вибрация по завершении (если устройство и браузер поддерживают эти возможности).
- Сохранение выбранного времени отдыха отдельно для упражнения.

### История и календарь
- Список завершённых тренировок с датой и количеством отмеченных подходов.
- Календарь с навигацией по месяцам и просмотром выбранного дня.
- Цветовая/символьная индикация выполненных, запланированных и пропущенных тренировочных дней.
- Отдельный список измерений массы тела с возможностью удалить запись.

### Прогресс
- График изменения массы тела по сохранённым измерениям.
- График динамики рабочего веса для выбранного упражнения.
- Отображение личного рекорда веса и лучшего результата по повторениям.
- Карточка цели по массе: текущий вес, целевой вес, полоса прогресса и расстояние до цели.
- Настройка целевого веса в профиле; карточка отображается во вкладке «Прогресс».

### Главный экран
- Виджет текущей массы тела и изменения за период измерений.
- Количество завершённых тренировок за текущий месяц и текущую неделю.
- Подсказка следующей тренировки.
- Быстрый запуск следующей тренировки.
- Просмотр всего тренировочного плана.

### Профиль и данные
- Добавление измерения массы тела (от 20 до 350 кг).
- Настройка целевого веса (от 20 до 350 кг).
- Выбор интервала напоминания о создании резервной копии: 7, 14, 30 или 60 дней.
- Экспорт данных в JSON-файл.
- Импорт данных из ранее созданной JSON-копии.
- Удаление всех локальных данных с подтверждением.
- Инструкция по установке приложения на главный экран.

## Тренировочный план

Текущий план состоит из трёх тренировок. В каждой тренировке предусмотрено по три подхода на упражнение по умолчанию; во время занятия можно добавить дополнительные подходы.

### Тренировка A — понедельник
**Грудь · трицепс · пресс · 10 упражнений**

1. Жим от груди в тренажёре
2. Наклонный жим от груди в тренажёре
3. Сведение рук в тренажёре («бабочка»)
4. Жим гантелей лёжа
5. Разгибание рук на верхнем блоке
6. Разгибание рук из-за головы
7. Обратные отжимания от скамьи
8. Подъём ног лёжа на скамье
9. Скручивания на наклонной скамье
10. Подъём коленей в тренажёре «капитанский стул»

### Тренировка B — среда
**Ноги · плечи · пресс · 11 упражнений**

1. Разгибание ног в тренажёре
2. Сгибание ног лёжа
3. Выпады назад
4. Разведение бёдер в тренажёре
5. Сведение бёдер в тренажёре
6. Подъёмы на носки сидя
7. Жим вверх в тренажёре на плечи
8. Махи гантелями в стороны
9. Подъём ног лёжа на скамье
10. Скручивания на наклонной скамье
11. Подъём коленей в тренажёре «капитанский стул»

### Тренировка C — пятница
**Спина · бицепс · пресс · 11 упражнений**

1. Пуловер с гантелью лёжа
2. Тяга в тренажёре сидя
3. Горизонтальная тяга нижнего блока
4. Обратная бабочка
5. Сгибание рук на бицепс в тренажёре
6. Сгибание рук на нижнем блоке
7. Молотковые сгибания с гантелями
8. Сгибание рук с гантелями на наклонной скамье
9. Подъём ног лёжа на скамье
10. Скручивания на наклонной скамье
11. Подъём коленей в тренажёре «капитанский стул»

Последовательность следующего занятия определяется по последней завершённой тренировке: A → B → C → A. Если завершённых тренировок ещё нет, первой предлагается тренировка A.

## Хранение и резервное копирование

FitTrack работает по модели **local-first**: история тренировок, измерения, настройки, цель по массе и черновик активной тренировки сохраняются в локальном хранилище браузера (ключ `fittrack-v1`).

**Важно знать:**
- Учётная запись и облачная синхронизация между устройствами не предусмотрены.
- Данные привязаны к браузеру/установке на конкретном устройстве.
- Очистка данных сайта, хранилища браузера или удаление данных приложения может привести к потере записей.
- Удаление и повторная установка PWA не следует использовать как способ обновления приложения.
- Для переноса данных на другое устройство используй экспорт JSON, затем импортируй файл на новом устройстве.
- Рекомендуется периодически сохранять резервную копию отдельно от телефона.

Экспорт включает завершённые тренировки, измерения массы тела, черновик текущей тренировки и настройки. Импорт заменяет текущие данные содержимым выбранной копии; перед импортом приложение запрашивает подтверждение.

## Установка на устройство

### iPhone и iPad

Приложение можно использовать прямо в браузере. В поддерживаемых браузерах доступна установка PWA.

## Технологии и структура проекта

Проект не требует отдельного сервера приложения или сборки:

- **HTML** — структура экранов и диалогов.
- **CSS** — адаптивный интерфейс и оформление.
- **JavaScript** — тренировки, таймер, графики, календарь, история и работа с данными.
- **Web App Manifest** — имя, режим отображения и параметры PWA.
- **Service Worker** — кэширование оболочки приложения и ресурсов, обновление версии кэша.
- **localStorage** — локальное хранение пользовательских данных.
- **SVG / PNG** — логотип и иконки приложения.

Основные файлы:

| Файл / каталог | Назначение |
|---|---|
| `index.html` | Разметка экранов, форм, диалогов и навигации. |
| `styles.css` | Стили и адаптация интерфейса под разные размеры экрана. |
| `app.js` | Логика приложения, план тренировок и управление локальными данными. |
| `manifest.webmanifest` | Настройки PWA. |
| `sw.js` | Service Worker и версия кэша. |
| `icons/` | Иконки и фирменный знак FitTrack. |
| `images/` | Локальные иллюстрации упражнений, если используются. |

Иллюстрации и анимации упражнений могут загружаться с внешних источников и поэтому не гарантированно доступны без интернета. Основные пользовательские записи хранятся локально.

## Публикация и обновление

Приложение публикуется через **GitHub Pages** из ветки `main`.

1. Изменения в исходниках фиксируются коммитами в репозитории.
2. GitHub Actions выполняет публикацию GitHub Pages.
3. Статус и журнал публикации доступны во вкладке [Actions](https://github.com/kirushakaichenkov1111-hub/fittrack-pwa/actions).
4. После успешной публикации приложение получает обновлённые файлы; Service Worker использует версию кэша из `sw.js`.

При изменении HTML, CSS, JavaScript, иконок или других кэшируемых ресурсов нужно проверить список файлов в `sw.js` и увеличить `CACHE_NAME`, чтобы устройства запросили актуальные ресурсы.

Не следует отмечать функцию как готовую только на основании идеи или незавершённого изменения: описание должно соответствовать проверенному коду и опубликованной версии.
